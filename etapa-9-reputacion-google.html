SOLICITUD DE REQUERIMIENTO A DESARROLLO

Etapa 9 · Reputación desde Google

Places API

  • Usar el Place ID guardado en la etapa 4.
  • Solicitar mediante FieldMask solo displayName, rating, userRatingCount, reviews y googleMapsUri necesarios.
  • Places devuelve como máximo una cantidad limitada de reseñas seleccionadas por Google.
  • Conservar atribuciones, enlaces y políticas de caché de Google Maps Platform.

Business Profile API

  • Usar únicamente para lugares cuyo propietario o administrador autorice el acceso mediante OAuth.
  • Requiere proyecto de Google Cloud, acceso aprobado y razón comercial válida.
  • Permite listar reseñas del perfil administrado y gestionar respuestas según permisos.
  • No pedir credenciales de Google dentro de SoloPropinas.

Regla de identidad

  • Las estrellas pertenecen al establecimiento.
  • Mostrar “Reputación del lugar en Google”.
  • No sumarlas al perfil personal del trabajador.
  • No inferir que una reseña del lugar califica al trabajador, aunque mencione su nombre.

Estados

  • Lugar sin Place ID o sin rating.
  • Datos públicos disponibles.
  • Perfil administrado vinculado o autorización vencida.
  • API no disponible, cuota agotada o acceso revocado.

Criterios de aceptación

  • No se solicitan estrellas después de una propina.
  • Cada rating muestra lugar, fuente Google y enlace correspondiente.
  • La interfaz distingue claramente trabajador y establecimiento.
  • Las llamadas se realizan desde backend con claves protegidas, cuotas y monitoreo.
  • La integración respeta términos de Google y permite desvincular el perfil.
